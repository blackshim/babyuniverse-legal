아기우주 계정과 관련 데이터의 삭제를 원하시면 아래 두 가지 방법 중 하나를 이용해 주세요.

1. 앱에서 직접 삭제 (즉시)

  1. 아기우주 앱 실행 → 로그인
  2. 홈 화면 오른쪽 위 톱니바퀴(⚙️ 설정) 아이콘
  3. 설정 화면 맨 아래 [계정 삭제]
  4. 안내 확인 후 [삭제]

2. 앱을 사용할 수 없는 경우 — 이메일 요청

aiopshwang@gmail.com 으로 "계정 삭제 요청"과 함께 로그인에 사용한 계정(카카오 또는 Apple)의 이메일 주소를 보내 주세요. 본인 확인 후 지체 없이 삭제해 드립니다.

삭제되는 데이터

  • 계정(로그인 식별자·이메일 등 계정 정보)
  • 커뮤니티 활동(익명 프로필, 작성한 글·댓글·좋아요)
  • 내가 시작한 AI 메이트 대화 기록 (다른 가족이 시작한 공유 대화에 남긴 발화는 가족 데이터로 보존)
  • 나 혼자 쓰던 가족의 경우: 아이 정보, 모든 양육 기록(수유·수면·기저귀·성장·접종·검진 등), 사진 전부

보존되는 데이터

  • 공동보호자(배우자 등)가 남아 있는 가족의 아이 정보와 양육 기록·사진은 남은 보호자를 위해 보존됩니다. 이 경우에도 기록에서 탈퇴자를 식별하는 정보는 제거됩니다.
  • 관련 법령에 따라 보존 의무가 있는 정보는 해당 기간 동안만 보관 후 파기됩니다.

삭제는 되돌릴 수 없습니다. 자세한 처리 기준은 개인정보처리방침을 참고해 주세요.
